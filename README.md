# 🎵 MusicByte

**Your offline music theory & audio engineering companion.**

A beautiful, dark-themed Flutter app packed with essential tools for musicians, producers, and audio professionals — all working 100% offline.

---

## ✨ Features

### 🎼 **Music Theory**
- Interactive **Circle of Fifths** with major & relative minor keys
- Detailed key pages: scales, diatonic chords, and note frequencies
- Guitar chord visualizer with smart voicings and inversions
- Interval & chord playback with high-quality sine-wave engine

### 🎛️ **Audio Tools**
- Professional **Chromatic Tuner** (microphone)
- **EQ Spectrum** visualizer
- **Rhythm Trainer** with customizable patterns
- **Metronome** with accent support
- **Ear Trainer** & Note Assault game
- Play notes, intervals, chords, and scales instantly

### ⚡ **Production Tools**
- Comprehensive **Pro Tools Shortcuts** reference
- Practice Log with streaks and weekly stats
- Offline-first with local persistence

### 🎨 **Design**
- Luxurious dark theme with multiple color schemes (Gold, Ocean, Forest, Rose, Mono)
- Smooth animations and responsive layout (mobile + desktop ready)
- Built with Material 3
